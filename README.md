# Multiverso-News
 NERDANDO | Portal Geek Cyberpunk
O Nerdando é um portal de notícias dedicado à cultura pop, animes, quadrinhos e games, desenvolvido com uma identidade visual moderna inspirada na estética neon e cyberpunk.

A ideia do projeto foi unir a paixão pelo universo nerd a uma estrutura Web sólida, garantindo que o site seja visualmente marcante, fluido e fácil de navegar.

 O que foi trabalhado no projeto
Interface Responsiva & Tema Neon: Criação de um layout adaptável para qualquer tela, utilizando paleta de cores vibrantes, sombras e efeitos visuais no estilo cyberpunk.

Código Limpo e Semântico: Estruturação das páginas utilizando HTML5 e CSS3 puros (sem frameworks), focando na organização visual do conteúdo.

Acessibilidade e SEO: Cuidados na hierarquia de textos, contraste de cores e marcações para facilitar a leitura por leitores de tela e otimizar a navegação.

Conteúdo Temático: Páginas de matérias individuais estruturadas para leitura dinâmica, com suporte a imagens e vídeos embutidos.

 Telas do Projeto
Página Inicial: Banner de destaque principal e grade para as últimas notícias do multiverso.

Matérias Dedicadas: Páginas exclusivas para conteúdos específicos, como a análise de Solo Leveling, curiosidades de Pokémon e o embate entre Capitão América vs. Homem de Ferro.
